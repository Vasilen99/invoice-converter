# Invoice Converter

Invoice Converter is a Next.js application designed to convert and manage invoices efficiently. This project utilizes the latest technologies, including Tailwind CSS for styling and ESLint for code quality.

## Features

- **Next.js**: A React framework for building server-side rendered applications.
- **Tailwind CSS**: A utility-first CSS framework for rapid UI development.
- **TypeScript**: Provides type safety and better tooling.
- **ESLint**: Ensures code quality and consistency.

## Getting Started

To get started with the Invoice Converter project, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone <repository-url>
   cd invoice-converter
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Open your browser**:
   Navigate to `http://localhost:3000` to see the application in action.

## Project Structure

- `public/fonts`: Directory for custom font files.
- `src/app`: Contains application-specific files including layout and global styles.
- `src/components`: Reusable components for the application.
- `src/lib`: Utility functions for code reusability.
- `src/types`: TypeScript types and interfaces for type safety.
